# Subscription Sumo

> Every subscription is a tiny wrestler trying to pin your bank balance.

Import bank exports and see recurring charges as sumo with weight, pin time, and ring pride. Throw the heaviest ones out when you cancel and record the pin as a saved dollar.

## Features
- Parse bank CSVs and detect recurring subscription patterns
- Render each subscription as a sumo wrestler with weight and pin score
- Drag-and-throw cancellation flow that records a local savings pin
- Weekly ring report ranking which subscriptions are stealing money

## Stack
- SvelteKit
- SQLite
- Recharts

## Getting started
```
npm install && npm run dev
```
